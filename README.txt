SIMON GAME CHALLENGE - COMPLETED

Files:
- index.html: game page (jQuery and game.js are linked)
- styles.css: original supplied styling
- game.js: completed Steps 1-10 from the PDF guide
- sounds/: original supplied audio files

HOW TO RUN
1. Extract this ZIP file.
2. Open the "Simon Game Challenge" folder.
3. Open index.html in a browser (internet connection is needed for the jQuery CDN).
4. Press any keyboard key to start.
5. Watch the colour sequence, then click the buttons in the same order.
6. Each correct round adds one more colour. A wrong choice ends the round;
   press any key to restart.

The starter styling and supplied sound assets are retained. The HTML row class typo
was corrected so the original two-row layout displays properly.
